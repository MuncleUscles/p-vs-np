# Reusable protocol integration notes

This pack contributes mathematical data, not transaction or merge authority. Compile `pack.json` into runtime policy only after independent review. Bind the exact protocol commit, separately chosen problem-repository commit, full policy SHA, trusted file closure, goal declaration and per-goal content fingerprint. `draft-unenrolled` cannot authorize submissions. No self-referential commit value is part of this source manifest.

The positive fixture is the disclosed `disjoint_sat` reference. It must verify as formally valid while remaining nonrewardable and excluded from the open earning queue. The four other statements have boundary checks but no proof fixtures. Only freshen_namespaces and cnf_restriction are launch reward candidates; clause_restriction is supporting-only and unit_propagation is deferred. Do not replace missing proofs with assumptions, placeholders, hidden reference solutions or `sorry`.

A trusted assembly loads `lean/Definitions.lean`, the selected `Statement.lean`, then exactly `theorem candidate : GoalType :=` and the permitted proof expression. The displayed statement and goal fingerprint must refer to those bytes. The common boundary checks are semantic sentinels, not assumptions supplied to candidates; do not make their theorem names available as credited proof dependencies. Do not import the reference into the unimplemented goals.

The existing old production grammar is insufficient for the disclosed reference, so syntactic support must be reviewed explicitly. Useful constructive proof constructs are `intro`, `constructor`, `obtain`, `have`, `let`, `refine`, `apply`, `exact`, `cases`, `induction`, `simp`, `simpa`, `rw`, `change` and `rfl`, with local typed functions and pattern binders. The reference already requires named Core List lemmas, membership and finite conditionals. Parity disjointness will likely need basic arithmetic simplification or `omega`; a small trusted smoke check confirmed bare Lean 4.19.0 supports `omega` with only `propext` and `Quot.sound`. This is a capability recommendation, not an audited permissive grammar. `Classical.choice` is not required by the intended constructive mathematics.

Core namespace allowance must not accidentally admit arbitrary commands or metaprogramming. Restrict the candidate to a bounded proof expression and isolate Lean with no network or credentials. Refuse imports, namespace/declaration escapes, extra axioms, `sorry`, options, macros, command elaboration and unsafe/native-evaluation escapes. Reject warnings, unknown axioms, wrong exact theorem types and altered definitions. No extra elaborator or package is requested by this pack.

Useful adversarial cases include omitting the unit membership assumption, conflating `none` and `some []`, deleting the variable-disjointness hypothesis, using a collapsing renaming, flipping literal signs, discarding an empty clause, claiming a proof of a weaker theorem, and submitting an unchanged reference as novel. Signed claims must bind the actual immutable PR head/base and record hash through the reusable protocol; the pack never chooses author wallets or scores itself.

Known limits: one-variable restriction and one unit step only; no recursive propagation, termination proof, DPLL completeness, polynomial-time construction bound, circuit encoding, SAT benchmark or P-vs-NP target. The graph may later record actual accepted dependency use, but suggested reading links are not payable dependencies.
